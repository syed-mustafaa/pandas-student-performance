# Student Performance Analysis

A data analysis project using Pandas to analyze student performance metrics.

## Features
- Calcluates average scores by subject.
- Identifies top-performing students.
- Analyzing correlation between attendance and scores.
- Generates visual reports (Bar charts and Scatter plots).

## Usage
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the analysis:
   ```bash
   python analysis.py
   ```
3. View the generated `performance_report.png`.
